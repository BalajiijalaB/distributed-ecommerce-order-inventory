# Distributed E-Commerce Order & Inventory System

## Overview

A full-stack e-commerce application designed to manage products, customer orders, inventory and payment workflows.

The project aims to explore backend development, database management, REST APIs, transactional operations, concurrency control and distributed-system concepts.

## Planned Features

- Product catalog
- User authentication
- Shopping cart
- Order management
- Inventory management
- Simulated payment processing
- Admin dashboard
- Stock consistency
- Concurrent order handling

## Technology Stack

- Java
- Spring Boot
- PostgreSQL
- React
- Redis
- Git
- Docker

## Architecture

The system will initially be developed as a modular backend application.

As the project progresses, selected components and workflows will be explored using distributed-system concepts.

## Development Progress

- Day 1: Project setup and architecture planning
- Day 2: Database design
- Day 3 onwards: Implementation

## Objective

Build a practical full-stack application that demonstrates software engineering, backend development, database design and system-design fundamentals.
